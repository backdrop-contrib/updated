Last Updated
======================

The Last Updated module provides a checkbox on the node form that allows
editors the choice to display an "Updated" date in addition to a "Submitted"
date.


Requirements <!-- Do not include this section if there are no requirements. -->
------------

none

Installation <!-- This section is required. -->
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.

- Visit the content type configuration pages under Administration > Strucrture >
  Content types (admin/structure/types).
  - Enable the option for as many content types as desired.

- Configure user permissions at Administration » People » Permissions
  (admin/people/permissions).
  - The permission Configure the display of the node last updated date grants
    the ability to toggle the display of the updated date on all node types.
  - People with the additional Administer content types permission will be able
    to set the default display (on/off) per node type.

- Create or edit any node to see the new checkbox under "Publishing options".
  Note: the last updated date is also visible under "Authoring information".
